# CAZpresent

Offizielle Installationsdateien von **CAZ Labs** für Windows und Android.
Dieses Repository verteilt ausschließlich fertige Programme und Prüfsummen.

**Produktinformationen:** [caz.de/cazpresent](https://caz.de/cazpresent)

## CAZpresent Free

Die kostenlose Ausgabe ist dauerhaft nutzbar und zeigt CAZ-Branding im Start- und Einrichtungsbereich. Der Präsentationsbereich bleibt neutral und kann ein eigenes Logo zeigen.

CAZpresent ist proprietäre Software. Die kostenlose Bereitstellung ist keine Open-Source-Lizenz. Hinweise und Lizenzen mitgelieferter Drittkomponenten bleiben erhalten. Der Windows-Installer ist nicht mit einem Authenticode-Zertifikat signiert. Windows kann deshalb einen unbekannten Herausgeber oder eine SmartScreen-Meldung anzeigen. Prüfen Sie Quelle und Prüfsumme; Schutzfunktionen müssen nicht pauschal deaktiviert werden.

Die Android-APK ist signiert und wird direkt als APK installiert. Android kann für die verwendete Download-App eine Erlaubnis zur Installation aus dieser Quelle verlangen. Eine macOS-Ausgabe ist noch nicht verfügbar.

Diese Version ist eine aktuelle Vorabversion. Prüfen Sie das Programm mit den vorgesehenen Geräten und Medien vor einem produktiven Messe- oder Veranstaltungseinsatz.
