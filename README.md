# CAZpresent

Offizielle Installationsdateien von **CAZ Labs** für Windows und Android.
Dieses Repository verteilt ausschließlich fertige Programme und Prüfsummen.

**Produktinformationen:** [caz.de/cazpresent](https://caz.de/cazpresent)

## CAZpresent Free

Die kostenlose Ausgabe ist dauerhaft nutzbar und zeigt CAZ-Branding im Start- und Einrichtungsbereich. Der Präsentationsbereich bleibt neutral und kann ein eigenes Logo zeigen.

CAZpresent ist proprietäre Software. Die kostenlose Bereitstellung ist keine Open-Source-Lizenz. Hinweise und Lizenzen mitgelieferter Drittkomponenten bleiben erhalten. Diese Beschreibung ist kein vollständiger Lizenzvertrag. Individuelle Anpassungen und die Partnerausgabe werden gesondert vereinbart.

Die Android-APK ist signiert und wird direkt als APK installiert. Android kann für die verwendete Download-App eine Erlaubnis zur Installation aus dieser Quelle verlangen. Eine macOS-Ausgabe ist noch nicht verfügbar.

Diese Version ist eine aktuelle Vorabversion. Prüfen Sie das Programm mit den vorgesehenen Geräten und Medien vor einem produktiven Messe- oder Veranstaltungseinsatz.

## LED-Wand und Sonderformat

Seit 0.3.8 optional: eigene Bildfläche mit Breite, Höhe und Position X/Y, Einpassen oder Beschneiden und Vollbild-Testbild. Für Bild-, Video- und PDF-Vollbild sowie Schleifen. Maximal 8192 Pixel je Achse einschließlich Position und 16.777.216 Pixel Fläche. Keine Änderung der HDMI-Auflösung und kein automatisches LED-Panel-Mapping. Vorab auf der tatsächlichen Hardware prüfen; noch kein physischer LED-Wand-Test. [Anleitung](https://caz.de/cazpresent#led).
